ASWIN & ATHIRA — WEDDING WEBSITE
=================================

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in your browser.
   For the best local development experience, open the folder in VS Code and use Live Server.

WHAT'S INCLUDED
- Animated editorial-style landing page
- Mobile-friendly responsive layout
- Couple photo gallery using your uploaded photos
- Live countdown to 31 October 2026, 11:00 AM IST
- Wedding and reception details
- Wedding invitation image section
- RSVP form that generates a message and lets guests copy it

IMPORTANT
- RSVP is front-end only: it does not send data to a server or email automatically.
- Venue directions use Google Maps search links; please verify the exact pin before sharing.
- Reception time is marked “Time to be confirmed” because it was not specified on the invitation.
- Wedding card and save-the-date artwork are included as supplied.
- Internet is needed for Google Fonts. The page still works without them using fallback fonts.


WHATSAPP RSVP SETUP
1. Open script.js in a text editor.
2. Find: const WHATSAPP_NUMBER = "91XXXXXXXXXX";
3. Replace it with the couple's WhatsApp number including country code, digits only.
   Example format for India: 919876543210 (example only, not a real contact).
4. Save the file and re-zip the website folder before uploading it.
When guests submit the form, WhatsApp opens with their RSVP message pre-filled. Guests must tap Send.
